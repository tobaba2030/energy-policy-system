# 项目记忆：虚拟电厂多时空尺度智能协同运营申报项目

## 项目定位
- 国家能源局"人工智能+"能源高价值场景试点申报
- 项目名称：虚拟电厂多时空尺度智能协同运营
- 申报单位：南网综合能源股份有限公司
- 2026年5月26日列入国家能源局首批51个"AI+能源"高价值场景清单（能源新业态类）

## 当前版本：v11（6板块格式+研究内容列表版）
- 按照国家能源局6板块格式：一背景与意义→二主要研究内容→三创新点→四资金情况→五项目整体计划→六待协调事项
- 主要研究内容以列表形式给出：课题总览表+各子课题任务分解表（序号/子任务/牵头方/参与方），**不详细展开任务情况**
- 5个子课题结构不变：感知（ML/AI认知）→决策（DRL核心引擎）→交易（AI辅助优化）→部署（边缘AI+可解释AI）→验证（AI全链条示范）
- 示范场景：深圳（商业+居民负荷型）+ 佛山（工业+分布式新能源型）

## 关键用户偏好
1. 不喜欢5个子课题全围绕DRL展开，DRL只能占1个子课题
2. 不喜欢"除AI化"——因为是AI+试点，AI要贯穿全链条
3. 场景是深圳和佛山，不是上海和山西
4. 偏好结构化表格输出、多层级结构
5. 占位符待填：XX大学、XX研究院、XX科技公司
6. 申报格式要求6个板块，研究内容不详细展开、用列表形式

## 技术栈
- Markdown → Word(docx) 生成链路：python-docx + lxml
- 中文字体：正文仿宋、标题黑体、表格表头浅蓝底纹+灰边框
- qn()函数必须用完整命名空间URI包装XML属性
- 保存路径用os.path.join(base_dir, filename)避免中文路径编码问题
