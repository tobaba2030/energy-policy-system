
# 能源电网领域科技项目申报书自动化生成技能

## 技能简介

本技能（sci-tech-project-proposal）专门用于能源电网领域科技项目申报书的自动化生成。基于AI辅助撰写流程，从项目概述到经费预算的全流程申报书生成，包含项目背景与战略对齐、研究现状分析、研究内容与技术方案、研究计划与进度安排、预期成果与考核指标、研究团队与保障条件、经费预算、风险分析与应对措施等完整结构。

**版本：v3.0.0** - 支持 Markdown 与 Word 双格式输出的科技项目申报书生成！

## 适用场景

- 能源电网领域科技项目申报书撰写
- 科研项目可行性研究报告编写
- 新型电力系统相关技术研究项目申报
- 新能源并网、消纳等专题研究项目申报
- 电力系统智能化、数字化项目申报

## 快速开始

### 1. 准备项目信息

在使用本技能前，请准备以下基本信息：

```
【项目名称】：项目的全称
【项目类型】：集中攻关类 / 示范试验类 / 应用推广类
【技术领域】：新型电力系统 / 新能源并网 / 人工智能应用 等
【核心需求】：简要描述项目要解决的核心问题
【申报单位】：申报单位名称
【负责人信息】：姓名、职称、研究方向
【预期经费】：总经费金额
【项目周期】：如：3年/2年等
【可选补充信息】：参考资料、数据来源、特殊要求等
【输出格式】：markdown/docx
```

### 2. 使用方法

#### 完整申报书生成

参考 [examples/sample_input.md](examples/sample_input.md) 准备项目信息，然后使用完整提示词模板生成申报书。

#### Word 格式输出

使用本技能包含的 `scripts/generate-docx.js` 脚本直接生成 Word 申报书。

```bash
# 确保已安装依赖
npm install docx

# 运行生成脚本
node scripts/generate-docx.js
```

生成的 Word 申报书特点：
- 中英混排字体（中文宋体，英文 Times New Roman）
- 自动生成目录（打开后按 Ctrl+A → F9 刷新）
- 规范的格式和排版
- 页脚自动显示页码

#### 分章节生成

如果需要，可以使用章节专项生成提示词，逐章节撰写：

- 项目概述与立项依据
- 研究现状与趋势分析
- 研究内容与技术方案
- 研究计划与进度安排
- 预期成果与考核指标
- 研究团队与保障条件
- 经费预算编制
- 风险分析与应对措施

### 3. 质量检查

申报书生成后，使用 [checklist.md](checklist.md) 进行质量检查，确保申报书质量。

## Word 申报书生成

### 文档格式规范

- **字体**：中文宋体，英文 Times New Roman（中英混排自动处理）
- **字号**：标题小二(36) > H1小三(30) > H2四号(28) > H3小四(24) > 正文小四(24)
- **行距**：1.5 倍行距
- **首行缩进**：正文缩进2字符
- **分页**：H1标题前强制分页
- **目录**：自动生成，需打开后按 Ctrl+A → F9 刷新
- **页码**：页脚居中

### 运行脚本

```bash
# 进入技能目录
cd .claude/skills/sci-tech-report-generation

# 运行生成脚本
node scripts/generate-docx.js
```

### 自定义内容

编辑 `scripts/generate-docx.js` 中的 `reportData` 对象，替换为您的申报书内容。

数据结构说明：
- `title`：申报书标题
- `sections`：章节数组
  - `heading`：一级标题
  - `subsections`：子章节数组
    - `heading`：二级标题
    - `content`：内容数组（支持字符串、带加粗前缀、列表等格式）

## 提示词使用技巧

### 提高申报书质量的要点

1. **提供充分的背景信息**：包括行业现状、技术趋势、已有基础等
2. **明确项目目标**：尽量量化，避免模糊描述
3. **突出创新点**：说明与现有研究的区别和优势
4. **提供数据支撑**：关键指标要有数据来源和依据
5. **考虑实际应用**：明确应用场景和推广价值
6. **做好经费预算**：预算编制要合理，依据要充分

### 迭代优化建议

1. **先搭框架再填内容**：先用技能生成申报书框架，再逐步完善细节
2. **分章节生成**：对重点章节可以单独调用，多次优化
3. **交叉验证**：使用不同的提示词方式生成，对比选择最优
4. **人工精修**：AI生成的申报书需要人工润色，确保专业准确
5. **合规性检查**：对照申报指南要求检查格式和内容

## 常见问题

### Q: 如何让生成的申报书更符合特定项目需求？
A: 请在输入信息中提供更多项目相关的背景、数据、偏好等信息，越详细生成效果越好。特别是申报单位信息、负责人信息、预期经费、项目周期等关键信息。

### Q: 生成的申报书可以直接提交吗？
A: AI生成的申报书可以作为良好的基础框架，但建议根据具体申报指南要求进行人工审核和优化，确保内容完整、数据准确、格式合规。

### Q: 申报书的字数大概有多少？
A: 根据项目类型和详细程度不同，一般在8000-25000字之间。

### Q: Word 申报书打开后目录不显示怎么办？
A: 打开 Word 文档后，按 `Ctrl+A` 全选内容，然后按 `F9` 键，选择「更新整个目录」即可。

### Q: 如何编制合理的经费预算？
A: 本技能提供经费预算专项生成模板，您可以根据项目实际需求调整各科目预算金额。预算编制要符合经费管理规定，与研究任务相匹配。
