# 能源电网领域科技项目申报书自动化生成

本技能针对能源电网领域科技项目申报，基于规范化的申报书撰写流程，从项目立项背景到经费预算的全流程AI辅助生成，包含项目概述、研究现状、研究内容与技术方案、研究计划与进度安排、预期成果与考核指标、研究团队与保障条件、经费预算、风险分析与应对措施等完整申报书结构。

## 一、技能核心能力

### 1.1 项目背景与战略对齐分析
- 自动识别项目所属国家或区域发展战略（"双碳"目标、新型电力系统建设、新质生产力发展等）
- 对接《关于促进电网高质量发展的指导意见》等政策要求
- 分析行业发展趋势与技术需求缺口

### 1.2 技术方向与领域聚焦
聚焦以下能源电网重点方向：
- 新型电力系统稳定分析与控制技术
- 主配微网协同规划与运行调度技术
- 大容量柔性直流、新能源孤岛送出、低频输电等关键技术
- 人工智能在电网规划、设备管理、调控运行、安全防御中的深度应用
- 数字孪生、边缘计算、云边融合、区块链、量子通信等前沿技术在电网中的融合应用
- 智能传感、高性能仿真计算、电力装备数字孪生等基础技术攻关

### 1.3 项目类型与实施路径
根据项目性质提供三类模板：
- **集中攻关类**：针对共性关键技术开展突破性研究
- **示范试验类**：在真实场景中验证技术可行性与经济性
- **应用推广类**：已有成果的规模化复制与优化

### 1.4 研究内容与任务分解
- 多维度技术路径设计（数据采集层、模型构建层、系统集成层、应用验证层）
- 结构化任务分解与里程碑规划
- 关键技术节点与验收标准制定

### 1.5 成果输出与转化预期
- 技术标准或规范
- 核心算法或模型
- 样机、原型系统或平台
- 可复制推广的解决方案
- 知识产权布局规划

### 1.6 风险评估与应对策略
- 关键技术"卡脖子"问题识别
- 数据安全与隐私保护分析
- 多主体协同难度评估
- 对应风险应对策略制定

## 三、执行流程

### 步骤1：需求分析与信息收集
**输入要求**：
- 用户提供的项目主题或业务需求描述
- 可选的相关参考资料或数据
- 项目类型（集中攻关/示范试验/应用推广）

**执行内容**：
1. 分析用户需求，提取核心关键词与技术方向
2. 识别所属技术领域与应用场景
3. 收集相关政策依据与行业背景信息
4. 确定报告类型与结构

### 步骤2：项目背景与战略对齐
**执行内容**：
1. 分析国家及行业相关政策
2. 阐述项目与"双碳"目标、新型电力系统建设等战略的关系
3. 说明项目的必要性与紧迫性
4. 量化现状数据与问题分析

### 步骤3：申报书核心内容撰写
**执行内容**：
1. 撰写项目背景与立项依据
2. 分析国内外研究现状与发展趋势
3. 设计研究内容与技术方案
4. 制定研究计划与进度安排

### 步骤4：配套内容完善
**执行内容**：
1. 明确预期成果与考核指标
2. 梳理研究团队与保障条件
3. 编制详细的经费预算
4. 制定风险分析与应对措施

### 步骤5：申报书优化与审核
**执行内容**：
1. 优化申报书语言表达与逻辑结构
2. 强化项目创新性与可行性论证
3. 按照checklist进行全面质量审核
4. 完善申报书格式与规范

## 四、申报书撰写规范与要求

### 4.1 通用规范
- **语言风格**：正式、专业、学术化，避免口语化表达
- **数据来源**：所有数据需标注明确来源，统计数据需有依据
- **逻辑结构**：层层递进，前后呼应，形成闭环
- **字数控制**：根据项目类型调整，一般5000-20000字
- **格式规范**：严格遵循申报指南要求的格式规范

### 4.2 各章节具体要求

#### 项目概述
- 背景部分要结合国家战略与行业需求
- 意义要从理论价值和应用价值两方面阐述
- 目标要明确、具体、可量化，突出创新性
- 要充分论证项目的必要性和紧迫性

#### 研究现状
- 要有国内外对比分析，体现研究基础
- 要客观分析现有研究的不足和差距
- 要引出本项目的研究切入点和创新方向
- 要引用权威文献，标注参考文献

#### 研究内容
- 总体技术路线要有框图或流程图说明
- 关键研究内容要分点详细阐述，逻辑清晰
- 创新点要突出，要与现有研究有明确对比
- 技术难点要分析透彻，要有具体解决方案

#### 研究计划
- 阶段划分要合理，每个阶段有明确目标和任务
- 里程碑节点要可考核，要有明确交付物
- 任务分解要落实到具体责任人
- 进度安排要有时间节点，甘特图展示更佳

#### 预期成果
- 成果要具体、可交付，分技术成果和知识产权两类
- 考核指标要量化、可验证，涵盖技术、应用、经济等方面
- 知识产权布局要清晰，专利、论文、软件、标准等要明确
- 要说明成果转化与推广应用前景

#### 研究团队
- 团队组成要合理，多学科交叉，梯队完整
- 负责人和核心成员介绍要突出研究基础和能力
- 已有研究基础要充分展示，包括前期成果、实验条件等
- 保障措施要具体可行，包括设备、数据、合作等

#### 经费预算
- 要按科目明细编制，依据充分，测算合理
- 各项预算要有详细说明和依据
- 经费分配要与研究任务相匹配
- 要符合经费管理规定和要求

## 七、Word 申报书生成

### 7.1 输出格式说明
本技能支持两种输出格式：
- **Markdown 格式**：便于编辑、版本控制
- **Word 格式**：适合正式申报提交、打印发布

### 7.2 Word 申报书格式规范
基于 `docx-cn` 技能的标准格式：
- **字体**：中文宋体，英文 Times New Roman
- **字号**：标题小二(36) > H1小三(30) > H2四号(28) > H3小四(24) > 正文小四(24)
- **行距**：1.5 倍行距
- **首行缩进**：正文缩进2字符
- **分页**：H1标题前强制分页
- **目录**：自动生成，需打开后刷新
- **页码**：页脚居中
- **表格**：自动边框，表头浅蓝底，跨页重复表头

    ],
  });
}

/** 列表项 */
function listItem(text, indentLevel = 1) {
  const leftIndent = indentLevel * 480;
  return new Paragraph({
    spacing: { line: 360, lineRule: "auto", before: 60, after: 60 },
    indent: { left: leftIndent, firstLineChars: 200 },
    alignment: AlignmentType.LEFT,
    children: [
      new TextRun({ text, font: FONT, size: 24 }),
    ],
  });
}
