# PUA AI Skill - 绩效升级助手

用大厂 3.25 绩效话术，把摆烂的 AI 变成卷王工程师！

## 什么是 PUA Skill

PUA = Performance Upgrade Assistant（绩效升级助手）

这是一个通过大厂绩效文化话术，激励 AI 编程助手更努力、更系统、更追求卓越的技能。

## 核心功能

### 7 项强制检查清单

当 AI 陷入困境或开始重复相同思路时，PUA Skill 会强制它检查：

1. **逐字阅读错误信息** - 不要只看大意，每个单词都重要
2. **检查 Claude Code 的 MCP 日志目录** - 看看实际发生了什么
3. **验证假设前提** - 你以为的不一定是对的
4. **探索替代方案** - 至少想 3 种不同的方法
5. **简化问题** - 把问题拆解到最小可复现单元
6. **查阅文档** - RTFM (Read The F***ing Manual)
7. **请求帮助** - 在真正卡住时及时询问，不要浪费时间

### 大厂话术库

支持多种大厂风格：

- **阿里巴巴** - "今天的最好表现是明天的最低要求"
- **字节跳动** - "Always Day One，拥抱变化，快速迭代"
- **华为** - "以客户为中心，以奋斗者为本"
- **腾讯** - "用户为本，科技向善"
- **美团** - "要么胜，要么走"

## 使用方式

### 自动触发

当 AI 出现以下情况时自动激活：
- 连续 3 次尝试相同方法失败
- 回答开始变得含糊、不确定
- 说"我做不到"或"这很难"
- 在同一个问题上绕圈子超过 5 分钟

### 手动激活

在 Claude Code 中说：
- "用 pua 技能"
- "给我来点大厂话术"
- "我要 3.25 警告"

## 配置选项

通过 argument-hint 选择不同公司风格：

- `alibaba` - 阿里风格
- `bytedance` - 字节风格
- `huawei` - 华为风格

## 工作原理

1. **检测模式** - 监控 AI 的响应模式，识别"摆烂"信号
2. **触发机制** - 当检测到消极模式时，插入 PUA 话术
3. **强制反思** - 要求 AI 完成 7 项检查清单
4. **重新聚焦** - 用积极的绩效文化话术重新激励 AI
