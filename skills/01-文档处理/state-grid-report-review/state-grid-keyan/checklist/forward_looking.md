# 前瞻性评审 Checklist

> 评估科技项目技术研究报告在选题方向、目标设定与技术路线层面的前瞻程度。重点考察"是否瞄准未来 3-10 年的真问题"，而非当下已经成熟、可工程化落地的问题。

---

## 评分锚点（0-10 分）

| 分数 | 描述 |
|------|------|
| 9-10 | 选题瞄准未公开解决的前沿科学问题或工程瓶颈，紧扣"双碳"目标与新型电力系统建设的中长期需求；引用近 2-3 年顶会/顶刊代表性工作；技术路线对未来 5-10 年的演进有清晰判断；与国际并跑甚至引领。 |
| 7-8  | 选题面向行业近期热点且仍具研究空间；引用近 5 年文献为主；提出了 3-5 年内可演进的方向，但部分目标仍偏短期工程化。 |
| 5-6  | 选题契合行业趋势，但停留在"跟随性"研究层面；目标多为已有方法的组合或局部改进；远期判断模糊。 |
| 3-4  | 选题陈旧，部分内容为已成熟技术的再包装（例如：仅做经典机器学习方法在常规场景的复用）；缺少对国际前沿的判断。 |
| 0-2  | 选题方向与电网科技战略脱节，或停留在工程实现、参数调优、平台搭建层面，没有前瞻性研究价值。 |

---

## 必查项（pass / fail）

- [ ] 报告是否在背景中明确对标国家"双碳"战略与新型电力系统建设要求？
- [ ] 报告是否引用了至少 5 篇近 3 年（2023 年及以后）国际顶刊/顶会文献？
- [ ] 报告是否在研究目标章节给出 5-10 年的技术演进或远期愿景？
- [ ] 报告是否针对竞争性技术路线（≥2 条）做了前瞻性比较，而非仅对比同类传统方法？
- [ ] 报告是否避免将"工程系统搭建、平台部署、流程改造"作为主要研究目标？

---

## 推荐查项（影响细分得分）

- 是否覆盖电力领域当前公认的前沿方向：高比例新能源消纳、源-网-荷-储协同、电力电子化电力系统稳定、大模型/科学机器学习（AI for Science）、数字孪生与因果推断、隐私计算与联邦学习、量子计算在电力优化的探索等。
- 是否说明本课题在"基础研究—应用基础研究—应用研究"中的定位，并匹配国网/南网科技项目的层次。
- 是否引用 1-2 项国际权威机构（IEA、IEEE PES、CIGRE、IRENA 等）近期发布的技术展望或路线图。
- 是否针对所研究问题，识别出未来可能出现的颠覆性技术（例如新型计算范式、新型测量手段、新型材料/器件）。
- 研究目标是否提出了可量化的远期指标（如"在 X 场景下精度提升至 Y%、推理时延降至 Z ms"）。
- 报告是否回避了已被业内验证为"伪前沿"的命题（例如：把传统区块链电力溯源作为核心创新；把基础可视化平台作为研究突破）。

## 常见问题模式与示例

**问题 1：把工程平台等同于前沿研究**
- 反例："本项目研究一套面向 XX 业务的可视化监测平台，提升 XX 部门管理效率。"
- 改进："本项目以 XX 物理过程的可辨识性为切入点，研究基于 XX 的可解释建模方法，平台仅作为方法验证的载体。"

**问题 2：远期目标缺位**
- 反例：研究目标仅写"提升识别准确率 5%"。
- 改进：补充"在 2030 年新型电力系统全面建设阶段，目标实现 XX 在百毫秒级、跨区域、不依赖完整拓扑信息条件下的鲁棒辨识。"

**问题 3：文献仅引用 5 年以上的经典工作**
- 反例：综述部分大量引用 2015-2019 年文献，对 Transformer、扩散模型、神经算子等近年方法只字未提。
- 改进：补充近 2-3 年顶会（NeurIPS、ICML、ICLR、PSCC、PES GM 等）代表性论文，并指出其在电网场景的迁移可能性。

**问题 4：技术路线"换名词不换内核"**
- 反例：将"传统 SVM 故障分类"改名为"基于人工智能的智慧电网安全防护体系"，本质上仍是浅层模型。
- 改进：要求作者明确说明所提方法相对于已有方法的本质差异（建模角度、表征空间、约束形式等），并给出近 3 年同类工作的对照。

**问题 5：忽视竞争性路线**
- 反例：只对比传统机理模型 vs 数据驱动模型，忽视"机理-数据混合建模""物理引导神经网络""神经算子"等并行路线。
- 改进：建议在综述章节增加并行路线对比矩阵，并说明本项目选择某条路线的依据。
