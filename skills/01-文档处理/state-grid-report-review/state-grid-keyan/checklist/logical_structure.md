# 整体逻辑结构评审 Checklist

> 评估科技项目技术研究报告在章节组织、论证链条、内容呼应等方面的逻辑严谨度。重点考察"背景—问题—综述—方法—预期成果—意义"的闭环是否成立。

---

## 评分锚点（0-10 分）

| 分数 | 描述 |
|------|------|
| 9-10 | 章节顺序符合学科研究逻辑；背景问题、文献综述、关键难点、研究内容、预期成果、应用意义一一对应；研究内容章节之间存在递进/并列/支撑的清晰关系；每一节首句即点明该节的逻辑位置。 |
| 7-8  | 章节顺序合理，主要内容能对应，但少数章节存在轻微跳跃或重复（如背景与意义重复表述、综述与现状混杂）。 |
| 5-6  | 章节顺序大体可用，但研究内容之间逻辑关系模糊；关键难点与研究内容未一一对应；存在 2-3 处明显内容空挂或重复。 |
| 3-4  | 逻辑链条断裂：综述与本项目方法之间缺少过渡；研究内容罗列堆砌而非递进；预期成果与研究内容对应不上。 |
| 0-2  | 章节顺序混乱，论证不成立；存在"自相矛盾"或"前后不一致"的表述。 |

---

## 必查项（pass / fail）

- [ ] 章节顺序是否覆盖：研究背景与意义 → 国内外研究现状 → 理论与方法依据 → 研究内容与技术路线 → 预期成果与应用 ？
- [ ] 第一章背景所提出的"痛点/科学问题"，是否在第三章/第四章被一一回应？
- [ ] 第二章综述章节末尾是否有"现有研究的不足 → 本项目的切入点"的过渡段？
- [ ] 第三章"关键点与难点"是否与第四章"研究内容"在数量、内容上一一对应？
- [ ] 第四章各研究课题之间是否说明了关系（递进 / 并列 / 支撑），而非平铺直叙的列表？
- [ ] 预期成果与各研究课题是否一一对应？是否存在"无来源的成果"或"无去向的研究"？

---

## 推荐查项（影响细分得分）

- 每个一级章节首段是否有"承上启下"的提示句？例如"在第二章综述工作基础上，本章……"。
- 是否避免将"研究意义"既写在第一章末尾又写在最后一章重复？
- 综述章节是否在末尾形成"研究不足清单"，并明确每条不足如何在后续章节被解决？
- 研究内容章节是否给出整体技术路线图（块图或泳道图），并在文字部分加以解读？
- 是否避免"内容空挂"：例如第二章详细介绍 GNN，但第四章方法完全未用 GNN。
- 是否避免"内容失落"：例如背景中提到三类问题，方法部分只解决一类，却未在范围/边界处说明。
- 各章末尾是否有总结性段落，将本章关键结论与下一章衔接？

---

## 常见问题模式与示例

**问题 1：综述 → 方法之间缺失"问题精炼"过渡**
- 反例：第二章末尾直接列出 10 余条参考文献后戛然而止，第三章直接开始介绍方法。
- 改进：在第二章末尾加一节"现有研究不足与本项目切入点"，凝练 3-5 条不足并对应到本项目计划的研究问题。

**问题 2：关键难点与研究内容不对应**
- 反例：第三章列出"难点 1：多尺度建模；难点 2：稀疏样本；难点 3：物理一致性"，但第四章三个课题分别是"数据采集系统、可视化平台、报告自动生成"，二者完全脱钩。
- 改进：研究内容必须围绕已识别的难点展开，每个课题至少回应 1 条难点。

**问题 3：预期成果与研究内容错位**
- 反例：第四章只设置 2 个课题，但第五章列出 10 项预期成果，且许多与课题无关。
- 改进：预期成果应能映射到某一具体课题；若有溢出成果，需说明其来源。

**问题 4：章节内容相互重复**
- 反例：研究背景写了 1500 字，意义又写了 800 字，绝大部分内容重复。
- 改进：背景重点写"问题/需求/政策驱动"，意义重点写"对学科与对电网的贡献"；二者不重叠。

**问题 5：研究内容章节平铺无逻辑**
- 反例：第四章 4 个课题写成 4 段并列文字，看不出彼此关系。
- 改进：在 4.1 开头明确说明"课题 1 提供数据基础，课题 2 给出建模方法，课题 3 实现优化求解，课题 4 验证应用"，体现递进/支撑关系。

**问题 6：边界条件不清**
- 反例：背景说要解决新能源消纳问题，但方法仅讨论某种特殊场景下的功率预测，未在范围中说明。
- 改进：在第三章或第四章开头补充"研究范围与边界"说明，避免读者误读。
