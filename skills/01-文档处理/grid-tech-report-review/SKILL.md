# 电网科技项目研究报告评审标准规范（v3.0）

针对电网领域科技项目**技术研究报告**进行专业评审，输出符合标准格式的Word评审报告。

## 一、评审维度体系

| 评审维度 | 权重 | 核心评审要点 |
|----------|------|--------------|
| 理论创新性 | 25% | 新理论/方法/机制提出、原创性、理论基础完整性 |
| 技术前瞻性 | 20% | 行业发展趋势把握、未来指引、技术先进性 |
| 逻辑结构 | 20% | 结构完整性、逻辑清晰度、章节关联性 |
| 表述规范性 | 20% | 文字精炼度、专业术语规范、图表规范性 |
| 研究价值 | 15% | 学术价值、应用前景、经济效益预测合理性 |

## 二、评分等级标准

### 单项评分标准

| 分数区间 | 等级 | 说明 |
|----------|------|------|
| 90-100分 | 优秀 | 表现突出，具有重要创新性和前瞻性 |
| 80-89分 | 良好 | 表现较好，有一定创新性和前瞻性 |
| 70-79分 | 合格 | 基本达标，存在改进空间 |
| 60-69分 | 基本合格 | 勉强达标，需较大改进 |
| <60分 | 不合格 | 不达标，需重大修改 |

### 综合评价等级

| 总分区间 | 综合评价 | 建议 |
|----------|----------|------|
| 90-100分 | 优秀 | 强烈推荐，具有重要学术价值 |
| 80-89分 | 良好 | 推荐，具有较好研究价值 |
| 70-79分 | 合格 | 建议通过，需完善改进 |
| 60-69分 | 基本合格 | 有条件通过，需补充完善 |
| <60分 | 不合格 | 不予通过，需重大修改 |

## 三、Word评审报告格式规范

### 3.1 文档结构

评审报告按照以下章节结构组织：

```
一、评审概述
二、五维评分对比
三、综合排名
四、各报告详细分析
五、综合结论
六、改进意见汇总
```

### 3.2 封面格式

| 元素 | 格式要求 |
|------|----------|
| 报告标题 | 居中、22pt、宋体、加粗 |
| 副标题 | 居中、22pt、宋体、加粗 |
| 项目名称 | 居中、16pt、宋体、加粗、段前1200 |
| 评审信息 | 居中、12pt、宋体、段后120 |

### 3.3 标题层级

| 标题级别 | 字号 | 对齐 | 加粗 | 段前/段后 |
|----------|------|------|------|-----------|
| 一级标题(H1) | 15pt(小三) | 左对齐 | 是 | 120/60 |
| 二级标题(H2) | 14pt(四号) | 左对齐 | 是 | 60/60 |
| 三级标题(H3) | 12pt(小四) | 左对齐 | 是 | 30/20 |

### 3.4 正文格式

| 元素 | 格式要求 |
|------|----------|
| 字号 | 12pt |
| 字体 | 宋体 |
| 对齐 | 两端对齐 |
| 行距 | 1.5倍 |
| 首行缩进 | 2字符(480) |

### 3.5 列表项格式

| 列表类型 | 首行缩进 | 字号 | 格式 |
|----------|----------|------|------|
| 主要优点 | 480 | 12pt | 粗体，标签"【主要优点】" |
| 主要问题 | 480 | 12pt | 粗体，标签"【主要问题】" |
| 问题子类 | 720 | 12pt | 粗体，如"理论创新性：" |
| 具体问题点 | 960 | 12pt | 普通，包含"•"符号 |
| 改进建议 | 720 | 11pt | 粗体，数字编号 |

### 3.6 表格格式

| 表格类型 | 行数 | 表头样式 | 对齐 |
|----------|------|----------|------|
| 报告基本信息表 | N+1 | 浅蓝底+加粗 | 居中 |
| 五维度评分对比表 | 7行 | 浅蓝底+加粗 | 居中 |
| 综合排名表 | N+1 | 浅蓝底+加粗 | 居中 |
| 推荐优先级表 | N+1 | 浅蓝底+加粗 | 居中 |

**表注格式**：居中、10.5pt、粗体，如"表1 报告基本信息"

## 四、评审报告章节要求

### 4.1 一、评审概述

- 说明评审依据和评审范围
- 列出被评审报告清单（表1）
- 简要说明评审方法和标准

### 4.2 二、五维评分对比

- 展示五维度评分对比表（表2）
- 各维度评分用分数表示，如"70分"
- 包含各报告在五个维度的横向对比

### 4.3 三、综合排名

- 展示综合排名表（表3）
- 包含排名、报告名称、总分、等级
- 按总分降序排列

### 4.4 四、各报告详细分析

每个报告按照以下结构分析：

**4.X 报告N（第X名，XX分，XX等级）**

#### 【主要优点】

- 列举3-5个主要优点
- 使用"•"符号开头
- 首行缩进720

#### 【主要问题】

按问题类别分组：

- **理论创新性**：理论基础、方法说明、模型构建等问题
- **技术前瞻性**：先进性、趋势把握等问题
- **逻辑结构**：章节关联、逻辑衔接等问题
- **表述规范性**：图表规范性、参考文献规范性等问题
- **研究价值**：应用前景、效益预测等问题

每个子类下：
1. 子类标题（粗体，首行缩进720）
2. 具体问题点（普通，首行缩进960，使用"•"）

#### 【改进建议】

- 数字编号（1. 2. 3.）
- 首行缩进720
- 11pt粗体

### 4.5 五、综合结论

#### 5.1 总体评价

- 概述4份报告的整体表现
- 指出最突出的报告
- 简要说明各报告的等级分布

#### 5.2 推荐优先级

- 展示推荐优先级表（表4）
- 包含优先级、报告、理由

### 4.6 六、改进意见汇总

#### 6.1 高优先级改进项（必须修改）

- 使用"●"符号
- 按报告分组
- 必须是影响评分的关键问题

#### 6.2 中优先级改进项（建议修改）

- 使用"○"符号
- 补充性改进建议
- 提升报告质量的建议

## 五、评审执行流程

### 5.1 信息收集

1. 读取报告文件（支持.docx、.pdf、.txt格式）
2. 提取报告基本信息（名称、字数、章节结构）
3. 分析报告核心内容

### 5.2 逐项评审

1. **理论创新性评审**：识别创新点、评估原创性
2. **技术前瞻性评审**：分析技术先进性、趋势把握
3. **逻辑结构评审**：评估结构完整性、逻辑清晰度
4. **表述规范性评审**：检查格式规范、专业术语使用
5. **研究价值评审**：评估应用前景、学术价值

### 5.3 问题识别

1. 识别各维度的具体问题
2. 评估问题严重程度（严重/一般/建议）
3. 提出针对性改进建议

### 5.4 报告生成

1. 按标准格式生成评审报告
2. 包含评分表、排名表、详细分析
3. 导出为Word格式

## 六、输出要求

### 6.1 必需输出

- 五维度评分表（表2）
- 综合排名表（表3）
- 各报告详细分析（优点、问题、建议）
- 推荐优先级表（表4）
- 改进意见汇总

### 6.2 格式要求

- 标题层级清晰
- 列表缩进规范
- 表格对齐统一
- 字体字号标准

### 6.3 Word文档要求

- 文件名格式：`电网科技项目研究报告对比分析报告_vX.docx`
- 包含封面、目录、正文
- 表格有表注
- 评审日期自动生成

## 七、质量控制

### 7.1 评审一致性

- 同一标准应用于所有报告
- 评分有理有据
- 问题描述具体明确

### 7.2 实用性原则

- 建议具有可操作性
- 优先级划分合理
- 关注实际应用价值

### 7.3 专业性要求

- 使用电网领域专业术语
- 分析深入透彻
- 结论客观公正
