
# 能源电网领域科技项目报告自动化生成技能

## 技能简介

本技能（sci-tech-report-generation）专门用于能源电网领域科技项目报告的自动化生成。基于AI辅助撰写流程，从项目策划到完整研究报告的全流程生成，包含项目背景与战略对齐、技术方向与领域聚焦、研究内容与任务分解、成果输出与转化预期等完整结构。

## 适用场景

- 能源电网领域科技项目申报书撰写
- 科研项目可行性研究报告编写
- 新型电力系统相关技术研究报告
- 新能源并网、消纳等专题研究
- 电力系统智能化、数字化项目规划

## 快速开始

### 1. 准备项目信息

在使用本技能前，请准备以下基本信息：

```
【项目主题】：项目的全称或核心内容
【项目类型】：集中攻关类 / 示范试验类 / 应用推广类
【技术领域】：新型电力系统 / 新能源并网 / 人工智能应用 等
【核心需求】：简要描述项目要解决的核心问题
【可选补充信息】：参考资料、数据来源、特殊要求等
```

### 2. 使用方法

#### 完整报告生成

参考 [examples/sample_input.md](examples/sample_input.md) 准备项目信息，然后使用完整提示词模板生成报告。

#### 分章节生成

如果需要，可以使用章节专项生成提示词，逐章节撰写：

- 项目概述与背景
- 研究现状与趋势分析
- 研究内容与技术方案
- 研究计划与进度安排
- 预期成果与考核指标
- 研究团队与保障条件
- 风险分析与应对措施

### 3. 质量检查

报告生成后，使用 [checklist.md](checklist.md) 进行质量检查，确保报告质量。

## 提示词使用技巧

### 提高报告质量的要点

1. **提供充分的背景信息**：包括行业现状、技术趋势、已有基础等
2. **明确项目目标**：尽量量化，避免模糊描述
3. **突出创新点**：说明与现有研究的区别和优势
4. **提供数据支撑**：关键指标要有数据来源和依据
5. **考虑实际应用**：明确应用场景和推广价值

### 迭代优化建议

1. **先搭框架再填内容**：先用技能生成报告框架，再逐步完善细节
2. **分章节生成**：对重点章节可以单独调用，多次优化
3. **交叉验证**：使用不同的提示词方式生成，对比选择最优
4. **人工精修**：AI生成的报告需要人工润色，确保专业准确

## 常见问题

### Q: 如何让生成的报告更符合特定项目需求？
A: 请在输入信息中提供更多项目相关的背景、数据、偏好等信息，越详细生成效果越好。

### Q: 生成的报告可以直接用于项目申报吗？
A: AI生成的报告可以作为良好的基础框架，但建议根据具体申报要求进行人工审核和优化。

### Q: 报告的字数大概有多少？
A: 根据项目类型和详细程度不同，一般在5000-15000字之间。
