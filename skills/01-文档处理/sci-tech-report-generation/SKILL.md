# 能源电网领域科技项目报告自动化生成

本技能针对能源电网领域科技项目，基于系统化的撰写流程，从项目策划阶段到完整研究报告的全流程AI辅助生成，包含项目背景与战略对齐、技术方向与领域聚焦、研究内容与任务分解、成果输出与转化预期等完整结构。

## 一、技能核心能力

### 1.1 项目背景与战略对齐分析
- 自动识别项目所属国家或区域发展战略（"双碳"目标、新型电力系统建设、新质生产力发展等）
- 对接《关于促进电网高质量发展的指导意见》等政策要求
- 分析行业发展趋势与技术需求缺口

### 1.2 技术方向与领域聚焦
聚焦以下能源电网重点方向：
- 新型电力系统稳定分析与控制技术
- 主配微网协同规划与运行调度技术
- 大容量柔性直流、新能源孤岛送出、低频输电等关键技术
- 人工智能在电网规划、设备管理、调控运行、安全防御中的深度应用
- 数字孪生、边缘计算、云边融合、区块链、量子通信等前沿技术在电网中的融合应用
- 智能传感、高性能仿真计算、电力装备数字孪生等基础技术攻关

### 1.3 项目类型与实施路径
根据项目性质提供三类模板：
- **集中攻关类**：针对共性关键技术开展突破性研究
- **示范试验类**：在真实场景中验证技术可行性与经济性
- **应用推广类**：已有成果的规模化复制与优化

### 1.4 研究内容与任务分解
- 多维度技术路径设计（数据采集层、模型构建层、系统集成层、应用验证层）
- 结构化任务分解与里程碑规划
- 关键技术节点与验收标准制定

### 1.5 成果输出与转化预期
- 技术标准或规范
- 核心算法或模型
- 样机、原型系统或平台
- 可复制推广的解决方案
- 知识产权布局规划

### 1.6 风险评估与应对策略
- 关键技术"卡脖子"问题识别
- 数据安全与隐私保护分析
- 多主体协同难度评估
- 对应风险应对策略制定

## 三、执行流程

### 步骤1：需求分析与信息收集
**输入要求**：
- 用户提供的项目主题或业务需求描述
- 可选的相关参考资料或数据
- 项目类型（集中攻关/示范试验/应用推广）

**执行内容**：
1. 分析用户需求，提取核心关键词与技术方向
2. 识别所属技术领域与应用场景
3. 收集相关政策依据与行业背景信息
4. 确定报告类型与结构

### 步骤2：项目背景与战略对齐
**执行内容**：
1. 分析国家及行业相关政策
2. 阐述项目与"双碳"目标、新型电力系统建设等战略的关系
3. 说明项目的必要性与紧迫性
4. 量化现状数据与问题分析

### 步骤3：技术方向与研究内容设计
**执行内容**：
1. 明确核心技术方向与创新点
2. 设计多维度技术路径（数据采集层、模型构建层、系统集成层、应用验证层）
3. 分解研究任务，形成结构化内容
4. 梳理关键技术难点与解决方案

### 步骤4：研究计划与进度安排
**执行内容**：
1. 划分项目阶段（通常3-4个阶段）
2. 设定各阶段里程碑与交付物
3. 制定详细的任务分解与时间节点
4. 明确各参与方职责分工

### 步骤5：成果与考核指标设定
**执行内容**：
1. 明确预期成果形式（论文、专利、标准、软件、样机等）
2. 制定可量化、可考核的技术指标
3. 设计应用验证与示范方案
4. 规划成果转化与推广路径

### 步骤6：风险评估与质量审核
**执行内容**：
1. 识别技术、管理、市场等各类风险
2. 制定相应的应对措施
3. 按照checklist进行全面质量审核
4. 优化完善报告内容

## 四、撰写规范与要求

### 4.1 通用规范
- **语言风格**：正式、专业、学术化，避免口语化表达
- **数据来源**：所有数据需标注明确来源，统计数据需有依据
- **逻辑结构**：层层递进，前后呼应，形成闭环
- **字数控制**：根据项目类型调整，一般3000-10000字

### 4.2 各章节具体要求

#### 项目概述
- 背景部分要结合国家战略与行业需求
- 意义要从理论价值和应用价值两方面阐述
- 目标要明确、具体、可量化

#### 研究现状
- 要有国内外对比分析
- 要客观分析现有研究的不足
- 要引出本项目的研究切入点

#### 研究内容
- 总体技术路线要有框图或流程图说明
- 关键研究内容要分点详细阐述
- 创新点要突出，要与现有研究有对比

#### 研究计划
- 阶段划分要合理，每个阶段有明确目标
- 里程碑节点要可考核
- 任务分解要落实到具体责任人（如果需要）

#### 预期成果
- 成果要具体、可交付
- 考核指标要量化、可验证
- 要与研究内容一一对应
