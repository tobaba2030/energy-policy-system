# 示例输入

## 示例1：单个业务需求

```
云南曲靖、昭通等地煤化工自备电厂参与电网调峰时，15分钟级响应指令的调度-交易数据传递准确率仅为75%（数据来源：参考陕西省发改委调峰业务数据，适配云南场景），导致自备电厂参与调峰积极性不足。
```

## 示例2：多个业务需求

```
需求1：目前云南曲靖、昭通等地煤化工自备电厂6kV系统扩建后，短路电流超标率达18%（数据来源：《云南电网2023年自备电厂运维报告》），同时参与电网调峰时，15分钟级响应指令的调度-交易数据传递准确率仅为75%（数据来源：参考陕西省发改委调峰业务数据，适配云南场景），响应时段划分模糊，结算流程耗时超24小时，导致自备电厂参与调峰积极性不足，且大电抗长期运行厂用电损耗较行业标准高8个百分点（数据来源：行业通用指标）
需求2：云南电网新能源装机容量超40GW（数据来源：《云南电网2024年运行报告》），消纳压力突出，但符合调节要求的自备电厂仅60%纳入电网统一调度（数据来源：参考全国调节资源统筹数据，适配云南场景），调峰顶峰灵活资源储备量缺口达25%，供需平衡时段调用效率较行业标准低18个百分点（数据来源：行业通用指标），未充分发挥自备电厂的调节潜力。
```
