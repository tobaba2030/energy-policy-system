# 科技项目申报策划简表快速检查清单

## 使用说明
在完成科技项目申报策划简表后，使用本清单进行快速自查，确保所有内容符合规范要求。

---

## 📋 检查清单

### 一、项目标题检查（共7项）
- [ ] 格式符合：《[限定约束条件/应用场景]+[研究对象/核心痛点]+[核心技术路径/技术方法]+[关键技术研究/装备研制/示范应用]》
- [ ] 紧扣国家重点方向（新型电力系统、新能源并网等）
- [ ] 锁定垂直细分场景（如农村配网、山地风电等）
- [ ] 直击行业真实痛点（如新能源消纳、电压暂降等）
- [ ] 融入前沿技术（多模态感知、云边协同、电力大模型等）
- [ ] 字数不超过39字
- [ ] **无具体地名、企业名**（严禁！）

### 二、业务问题检查（共6项）
- [ ] 包含关键现状量化指标
- [ ] 所有数据指标标注清晰的数据来源
- [ ] 300字以内
- [ ] 明确问题对业务的负面影响（安全、运维、效益、消纳等）
- [ ] 不描述技术问题/技术路线，只阐述真实电网业务痛点
- [ ] 字数控制在250-280字范围内

### 三、预期成效检查（共6项）
- [ ] 240-280字
- [ ] 量化指标与业务问题现状指标一一对应
- [ ] 明确成果应用场景
- [ ] **不包含技术指标**（算法准确率、系统延迟等）
- [ ] **不包含知识产权、论文、人才培养**等非业务类成效
- [ ] 语言自然流畅，避免机械堆砌

### 四、研究内容检查（共7项）
- [ ] 开篇总起：用1句话点出核心痛点和研究目标
- [ ] 3-5个研究点
- [ ] 每个研究点80-100字
- [ ] 遵循"研究+具体场景/对象+核心技术路径+预期效果"句式
- [ ] 每点提及具体技术方法
- [ ] 结尾落地：包含示范应用
- [ ] 字数控制在450-500字（含空格、换行）

### 五、考核指标检查（共7项）
- [ ] 4-5个考核点
- [ ] 每个考核点以"形成/建立/研发/搭建/研制+具体成果形式"开篇
- [ ] 每个指标包含具体量化数值（≥、≤、%、小时等）
- [ ] 体现成果的应用场景或适配范围
- [ ] 部分指标明确试点应用要求
- [ ] 最后一点体现技术水平或可复制推广价值
- [ ] 所有指标与研究内容强关联

### 六、整体逻辑检查（共4项）
- [ ] 业务问题→研究内容→预期成效→考核指标形成完整闭环
- [ ] 无指标脱节
- [ ] 无逻辑断层
- [ ] 无空话套话

---

## ⚠️ 一票否决项（必须满足）

以下项目如有任何一项不满足，可能被形式审查直接否决：

1. [ ] 项目名称直接描述技术路线/技术方法，未凝练业务痛点
2. [ ] 业务问题无关键现状量化指标
3. [ ] 业务问题描述技术问题/技术路线，而非真实电网业务痛点
4. [ ] 预期成效堆砌过多技术细节、技术参数
5. [ ] 预期成效未与业务问题核心指标一一对应

## 💡 快速提示

### 通用化替换（重要！）
输出中严禁出现具体地名、企业名，请使用以下通用术语替换：

| 具体表述 | 通用替换 |
|---------|---------|
| 云南电网 | 某省级电网 / 区域电网 |
| 曲靖、昭通 | 典型地区 |
| 煤化工自备电厂 | 高耗电工业园区自备电厂 |
| [具体企业名] | 典型企业 |
| [具体地名] | 典型地区 / 试点区域 |

### 字数估算参考
- 中文：约1字/字符
- 标点符号：约1字/个
- 空格、换行：计入字数

### 数据来源标注
- 正式来源：《XX报告》、《XX规范》
- 参考来源：参考XX数据，适配XX场景
- 行业通用：行业通用指标、行业标准
